# 知序 · 个人知识、经验与数字记忆数据库

把工作、学习与生活中的记录、附件、知识、案例和项目联系起来：先快速记下，再整理、核对、搜索和复用。

本仓库提供 **Windows 本机单人应用的源代码**，界面为简体中文。目前是 `0.1.0-preview.5` 源码试用候选版本，需要 Python 环境；不包含独立 EXE、Python 运行时、模型权重或个人数据。默认仅监听 `127.0.0.1`。

## 日常使用

- **随手记与草稿**：网页提供工作、设备、学习和生活提纲，文字停止编辑后自动暂存到本机数据库，刷新后可以继续。点击确认保存才进入收集箱；网页附件需最终保存上传，不随文字自动暂存。
- **桌面采集**：控制台运行期间用 `Ctrl + Alt + Space` 唤出随手记，点击“粘贴截图”添加剪贴板图片，`Ctrl + Enter` 保存。快捷键冲突时仍可使用按钮；退出控制台后注销快捷键。
- **AI 整理与人工审核**：每日、周/月整理生成待审核草稿。可编辑、对照原文与出处，选择是否采用段落建议，再确认归档。AI 不自动确认记录，也不保证生成内容正确。
- **计划转待办**：从审核稿明确的计划段落提取候选，逐项核对标题、日期与关联资料后创建任务，保留来源并防止重复创建。
- **知识与项目管理**：管理记录、知识、案例、经验、问题、解决方案、项目与任务，通过标签、关系和来源组织资料。
- **附件与检索**：附件文字提取、图片 OCR、关键词检索与可选中文语义搜索；本机资料问答显示出处，便于返回原文核对。
- **可选语音采集**：用户主动录音或上传音频，经本机转写、人工校对后保存文字和原始音频；语音依赖与模型单独准备。
- **备份与迁移**：完整 ZIP 包含数据库、已登记附件、配置与外观偏好，支持校验、恢复、迁移和升级前备份；支持多种资料导出格式。

## Windows 快速开始

1. 下载或克隆仓库到有写入权限的文件夹。
2. 安装 **Python 3.11 或以上**，勾选添加到 PATH，并安装 Tcl/Tk（桌面界面需要 Tkinter）。
3. 双击 `control.bat` 打开桌面控制台，或双击 `run.bat` 启动网页服务。首次创建虚拟环境和安装依赖需要联网。
4. 完成欢迎设置，先用虚构记录验证采集、审核与完整备份，再录入自己的资料。

网页默认地址为 `http://127.0.0.1:8000`。如端口被占用，可复制 `.env.example` 为 `.env` 并修改 `APP_PORT`；`APP_HOST` 保持 `127.0.0.1`。

## 将数据放在 D 盘

程序与数据可以分开保存。全新安装首次启动前，将 `.env.example` 复制为 `.env`，例如设置：

```dotenv
APP_HOST=127.0.0.1
APP_PORT=8000
PLD_HOME=D:/ZhixuData
```

不额外指定 `DATABASE_URL`、`ATTACHMENT_DIR` 和 `BACKUP_DIR` 时，数据库、附件、备份、导出、模型缓存和配置跟随这个数据根目录。数据库默认位于 `data/personal.db`；设置页“系统信息”显示实际路径。

**已有数据时，修改 `PLD_HOME` 不会自动搬迁资料。** 先用旧版本生成完整 ZIP 并保存对应程序版本，关闭服务，再在新目录启动同版本程序并恢复、检查。换机不复制旧虚拟环境；恢复后重新准备所需模型和云端密钥。不要在运行时单独复制 `.db` 充当完整备份。

升级前先备份，保留旧程序与备份。程序检测到数据库迁移时会先生成升级前备份；恢复要求备份与软件数据库版本匹配，旧版备份应先用对应版本恢复，再升级。更多步骤见 [试用与分发说明](docs/DISTRIBUTION.md)。

## 可选模型与 AI

基础记录、管理、备份和关键词检索不需要云端 AI。OCR、语义搜索、Ollama 整理与语音各有依赖或模型要求；安装界面不代表模型已经准备完成。依赖安装和模型首次准备可能联网，完整本机模型准备后可以在本机处理资料。

在界面检查对应能力状态，按提示明确准备模型。本机整理需要安装 Ollama；语音功能先安装可选依赖，再重新启动程序并在语音页面准备模型：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-speech.txt
```

云端兼容服务需自行配置 HTTPS 地址和密钥，并明确同意发送选中资料；云端整理授权不启用云端资料问答。AI、OCR 与语音结果都需要人工核对，尤其是姓名、日期和数值。

## 数据与外观

本仓库不包含个人数据库、附件、实际 `.env`、配置、密钥、模型、日志、备份、导出、私人截图或角色原图。日常保存资料不会将数据库上传到 GitHub；请保持运行数据和密钥不受 Git 跟踪。

隐私等级用于资料筛选，**不是磁盘加密**。完整数据库导出和完整备份包含全部数据，不按隐私等级过滤，应自行妥善保管。

仓库默认素白皮肤；暖色皮肤使用通用枫叶 SVG。个人界面使用的角色参考图片不在仓库中。网页尚未上传的附件和桌面 `capture-temp/` 未提交截图不在完整 ZIP 内；桌面文字跨退出不会自动恢复，应先保存。

## 开发与验证

在项目根目录创建环境并安装锁定依赖：

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
.venv\Scripts\python.exe -m pytest -q
```

有 Node.js 时可检查前端暂存、离页保护与审核差异逻辑；日常运行不需要 Node.js：

```powershell
node --test tests/test_ai_review_tools.cjs tests/test_capture_workspace.cjs tests/test_capture_navigation.cjs
```

后端使用 FastAPI、SQLAlchemy、SQLite 与 Alembic，前端使用原生 JavaScript，桌面控制台使用 Tkinter。主要目录为 `app/`、`app/static/`、`database/versions/`、`scripts/` 和 `tests/`。

源码试用 ZIP 可按允许清单构建到新的路径；脚本拒绝覆盖已有 ZIP，并生成 SHA256 清单：

```powershell
.venv\Scripts\python.exe scripts\build_release.py --version 0.1.0-preview.5 --output dist\zhixu-0.1.0-preview.5.zip
```
