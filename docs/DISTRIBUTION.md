# 试用与分发说明

当前可以构建可检查的源代码试用候选 ZIP；这不是独立 EXE 安装程序，也没有对外发布。初次目标是少量 Windows 本机试用，先验证使用体验，再确定推广定位。

## 构建候选包

在项目目录使用现有 Python 环境：

```powershell
.venv\Scripts\python.exe scripts\build_release.py --version 0.1.0-preview.5 --output dist\zhixu-0.1.0-preview.5.zip
```

输出必须是新的 ZIP 路径，脚本拒绝覆盖已有文件。构建只读取允许的程序文件，不读取现有数据目录，不启动数据库或模型，不联系任何人，不上传或发布文件。可用 `--output` 指定临时目录验证。

包内 `release-manifest.json` 列出每个文件的 SHA256、版本、默认界面和源码变体。第三方依赖版本固定在 `requirements.lock.txt`，构建不捆绑 Python 或虚拟环境。未来增加程序目录或静态文件时，需审查并更新脚本 allowlist。

## 包含与排除

包含程序 Python 模块、明确列出的前端资源、数据库迁移、启动与模型准备脚本、依赖锁和通用说明。本轮允许清单新增网页文字草稿、人工待办跟进、桌面剪贴板与全局快捷键模块，包含 `20261004_capture` 迁移。根目录 README 与 `.env.example` 由脚本生成，避免携带本机配置或这台电脑的说明。

排除实际 `.env`、`config.json`、AI 设置、密钥、数据库、私人附件、未提交的临时截图、导出、模型权重、日志、备份、测试数据与界面截图、`.venv`、Git 元数据及缓存。只遍历 allowlist 的程序目录与文件；不会把整个项目或数据目录直接压缩。

用户提供的四张角色参考 JPEG 不随候选包分发。候选包默认 **素白、无角色插画、无动态**；暖色皮肤保留色彩与枫叶，但网页人物引用替换为包内通用 SVG，桌面人物图片关闭。个人使用版本的原图和偏好不受构建影响。项目名称、图标和第三方依赖的发布许可仍需逐项确认，见包内 `THIRD-PARTY-NOTICES.md`；不能把用户提供个人参考图理解为已经获得商业分发许可。

## 在另一台电脑试用

1. 将 ZIP 完整解压到新的可写文件夹。不要把候选包覆盖到正在使用的数据库目录。
2. 安装 Python 3.11 或以上版本，Windows Python 包含 Tcl/Tk。双击 `control.bat` 或 `run.bat`；首次创建虚拟环境和安装依赖需要网络。
3. 默认只连接本机 `127.0.0.1`，全新安装由欢迎设置开始，不带任何原用户的资料。数据默认在解压目录下保存；可复制 `.env.example` 为 `.env`，设置自己的 `PLD_HOME`，并保持数据库、附件和备份地址为默认跟随该目录。
4. OCR、中文语义搜索与本机 AI 整理是分别准备的能力。依赖安装和模型首次准备可能联网，需要磁盘空间；本包不带模型权重。安装核心界面并不表示这些模型已准备。模型准备完成后可以在本机运行，云端 AI 需用户自行设置并启用。
5. 打开“设置与备份”生成完整备份；先用虚构记录验证保存、附件、AI 审核、恢复，再保存重要资料。试用反馈不得自动包含记录、API 密钥或整份数据库。

### 日常采集与跟进

网页 **“随手记与草稿”**（`#quick`）提供工作、设备、学习和生活等场景提纲，提纲只添加填写提示，不生成事实。正文、标题、日期、隐私与关联项目停止编辑约 1.5 秒自动暂存到 SQLite；暂存成功后刷新可在“我的草稿”继续，收起后可恢复。冲突时对照服务器版本或明确另存新草稿。只有点击确认保存才进入收集箱与 AI 整理，提交重试复用同一原始记录，不覆盖后来手工修改。

网页仅自动保存文字草稿。待上传附件暂留页面内存，关闭或刷新前应完成最终保存，部分上传失败可继续补传。桌面录入文字也暂留窗口内存，跨退出不自动恢复。桌面“粘贴截图”仅在用户点击时读剪贴板图片，先保存到数据库旁的 `capture-temp/`：默认安装在解压目录的 `data/capture-temp/`，自定义数据库路径时跟随该路径。上传核对成功后清理本窗口创建的临时图片，失败、收起或退出保留未上传截图并提示恢复位置；可重新通过文件选择器添加，不自动扫描或上传旧截图。这些未提交图片不在完整 ZIP 中，须先作为附件保存或另行保留。

控制台运行时注册 **Ctrl + Alt + Space** 打开桌面随手记，退出后注销；冲突时提示并保留按钮入口，**Ctrl + Shift + Space** 仍只是控制台内快捷键。尚未实现桌面拖放。

AI 草稿详情的 **“后续事项转为待办”** 只读取明确的计划段落。用户逐项核对原句、标题，可选日期、项目与原记录，再点击确认创建。没有后台自动建任务或推断完成情况；创建待办也不确认 AI 归档。重复创建返回已有任务且保留之后的手工修改，普通任务编辑保留来源，来源与项目隐私上调会保护相应待办。

### 可选本机语音

“语音随手记”支持上传音频或由用户点击开始浏览器录音；不会自动监听麦克风。音频转写单个不超过 25 MB / 10 分钟。转写结果先显示在编辑区，用户核对并确认后，文字进入收集箱，原录音作为附件、机器原始转写作为扩展字段保留。未保存的录音与文字暂留当前浏览器，可先下载原录音；上传附件失败后仍保留本页录音并允许重试。

个人使用环境已用约 15 秒合成中文 WAV 验证“本机转写 → 人工校对 → 保存文字和原始音频”，记录详情可展开原始转写。识别出现文字错误，不能作为准确率保证；试用者仍需验证自己的麦克风、姓名数值、环境噪声和处理速度。候选包不携带该演示录音或现有模型缓存。

语音组件为可选依赖，启动程序不会自动安装。使用项目虚拟环境执行：

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-speech.txt
```

安装后重新启动数据库，进入“语音随手记”，明确点击“准备所选本机模型”。base 约 148 MB、small 约 486 MB，下载到数据目录固定的 `models/speech`；只有模型准备会联网下载，转写使用完整的本机模型路径。库版本固定为 `faster-whisper==1.2.1`，模型仓库固定到检查过的 revision。实现依据 [faster-whisper 官方 README](https://github.com/SYSTRAN/faster-whisper)、[官方 PyPI 包](https://pypi.org/project/faster-whisper/) 和发布者的 [base](https://huggingface.co/Systran/faster-whisper-base/tree/main)、[small](https://huggingface.co/Systran/faster-whisper-small/tree/main) 模型文件清单。

## 完整备份与换机

新的数据库完整 ZIP 包含校验清单、数据库、配置、登记附件与合法的 `appearance.json` 外观偏好。数据库包括所有状态的文字采集草稿、AI 草稿、审核历史和人工跟进待办来源，不按隐私等级过滤。全库 JSON 同样保留这些表，但普通记录导入器不接收全库 JSON，完整恢复仍使用 ZIP。网页未上传附件与桌面 `capture-temp/` 的未提交截图不在 ZIP 内。

恢复时保留本机数据目录配置；外观与数据一并恢复，出现写入失败或进程中断时按恢复日志回滚到原始外观文件。外观回滚快照损坏会保留恢复材料并中止恢复，不带着未验证的偏好继续替换数据库。本轮新增 `20261004_capture` 迁移；服务检测到旧库需要升级时先生成 `before_upgrade` 完整备份，保留原始记录。备份版本必须与恢复软件匹配，旧版备份先用对应软件恢复，再升级。

与当前数据库版本匹配的旧 ZIP 如果没有 `appearance.json`，恢复后当前界面偏好保持不变。皮肤图片属于程序资源，不在数据库备份内。换机需同时保留对应软件版本；人物图需要自行管理与确认用途，公共候选包不带个人角色图片。
