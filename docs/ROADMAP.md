# 知序产品规划：减少日常整理负担，并为未来推广准备

目标是让个人工作、学习与生活资料更容易记录、核对和复用，并为未来推广准备。推广采用“少量试用 → 可公开下载 → 持续服务与商业化验证”的顺序。当前仍是本机单人应用，目标用户和推广定位尚未确定。以下区分本轮已实现能力与后续验收，不能把候选包或受控测试当成已经公开发布、完成真实场景质量验证。

## 第一阶段：快捷采集与审核增强

**本轮已实现**：

- 网页“随手记与草稿”：`#quick` 可插入场景提纲，正文、标题、日期、隐私与项目停止编辑约 1.5 秒自动暂存到本机 SQLite。提纲只提供填写提示，不编造事实。刷新后在“我的草稿”恢复；收起和恢复是软状态，版本冲突可对照或另存。只有用户确认提交才进入收集箱与 AI 整理，重复提交不覆盖后来编辑的原记录。
- 网页附件仍需最终确认上传，只在当前页面内存保留，不随文字自动暂存。完整 ZIP 与全库 JSON 保留所有状态的文字草稿；完整恢复使用 ZIP，普通记录导入器不接收全库 JSON。
- 桌面“随手记”：控制台运行期间可用系统快捷键 Ctrl + Alt + Space 打开，冲突时提示并保留按钮入口；原 Ctrl + Shift + Space 仍限控制台内使用，Ctrl + Enter 保存。明确点击“粘贴截图”才读取剪贴板图片，暂存到数据库旁的 `capture-temp/`；默认位于数据目录的 `data/capture-temp/`。上传核对成功后清理本窗口创建的临时图，失败、收起或退出保留未上传图片并提示找回位置；这些临时图不在完整 ZIP 内。桌面文字跨退出不自动恢复，未实现桌面拖放。
- 审核稿停止编辑约 2 秒自动暂存到服务器，保存期间继续输入会再次保存；确认归档先保存最新修改。版本冲突时停止自动写入，浏览器会话缓冲可对照后明确恢复，不能静默覆盖服务器新版本。
- 原文、附件引用在本页展开定位；文字差异可与原始记录或打开时的审核稿对照，长文预览有明确上限。差异和引用检查不判定事实真伪。
- 选中段落后生成只读文字建议，附有限引用和提示。用户点击采用才替换选段，版本或选段变化后旧建议作废；不自动归档。
- 可选语音随手记：录音或上传、本机转写、人工核对后保存收集箱，保留原音频和机器原始转写。`requirements-speech.txt` 单独安装，base/small 模型由用户显式准备；未准备时不自动下载或发送云端。
- 全部待审核：网页、桌面审核按钮和托盘审核动作均可查看跨日期的待审核草稿，按页继续处理历史内容。

**此前本机验证**：随手记窗口与实际保存、审核自动暂存、选段建议和人工采用。此前测试环境准备了 base 语音模型，用约 15 秒合成中文 WAV 完成本机转写、人工校对和原音频保存，记录详情可查看机器原始转写；识别存在文字错误，因此该验收证明流程可用，不证明准确率。新增文字草稿的旧库保留迁移、并发版本、确认提交、回收站与完整备份恢复已用隔离库测试。

**后续验收**：在日常中文录音中验证姓名、数值、环境噪声、CPU 速度与磁盘占用，在不同 Windows 硬件和 DPI 下继续核对窗口、快捷键、剪贴板格式及托盘体验。拖入文件仍是后续采集优化，不列为已完成。

完成标准：用户能快速保存素材，稍后继续审核；AI 生成或改写的内容只有在用户确认后才归档；来源与手动修改可追溯。

## 第二阶段：数据库问答与复盘草稿

**本轮已实现**：

- “问我的资料”：先检索最多 8 个片段，再由本机 Ollama 生成逐条引用的回答。可按日期与项目缩小范围，排除回收站与隐私等级 3；资料不足时说明缺口。问答只在页面展示，不写入归档。云端整理授权不启用云端问答。
- 周/月复盘草稿：按自然周或自然月汇总普通记录和收集箱；同样修改、核对并确认归档。可手动选历史周期，自动周/月开关默认关闭；服务运行并到 `daily_time` 之后，只检查上一完整周期，不自动补齐全部历史。
- 后续事项转为待办：待审核或已归档草稿中明确的“后续计划 / 下一步”等段落可逐项核对标题、可选日期、项目与原记录，再人工确认创建。没有自动推断日期或后台创建任务；创建不代替归档确认，不表示已完成。同一草稿同一候选重复返回已有任务，普通任务编辑保留原句和草稿来源，来源与关联项目隐私上调传递到待办。
- 桌面收起到托盘、待审核数量与新草稿提示；新完整 ZIP 包含 `appearance.json`，旧 ZIP 恢复保留当前偏好，失败或中断时外观随恢复事务回滚。

**此前本机验证**：在隔离合成资料库用真实本机模型完成带出处的资料问答、选段建议和三个原始记录生成自然周待审核草稿；当次完整备份包含外观偏好，已有原始记录与升级前一致。

**后续验收**：用不同长度和表达的真实资料核对问答相关性、引用与模型结论，抽查周月复盘的完整性和重复生成行为。备份恢复和升级需继续在全新 Windows 环境验证；自动测试不能代替长期使用或 AI 准确率验证。

完成标准：常见问题能快速跳回出处；复盘可修改与审核，重复操作不会生成多个不可区分的归档；备份与恢复在隔离数据中验证。

## 第三阶段：少量试用

**本轮已实现的准备**：候选版本 **`0.1.0-preview.5`**，只按允许清单构建不含个人数据的源代码 ZIP，使用素白默认皮肤和通用枫叶素材。允许清单包含网页文字草稿、人工待办跟进、桌面剪贴板与全局快捷键模块，以及 **`20261004_capture`** 迁移。排除实际数据库、配置、密钥、附件、未提交截图、模型、日志和界面截图，以及四张个人角色参考 JPEG。候选包不捆绑 Python，不是独立 EXE，也未公开发布；详见 [试用与分发说明](DISTRIBUTION.md)。

**后续验收与决策**：

- 明确首批对象：优先选择有日常记录和经验复用需求的人，收集实际场景，再确定职业经验库、通用个人工具或企业知识系统中的首个方向。
- 用全新 Windows 用户环境验证首次安装、离线运行、模型准备、数据目录选择、更新前备份和完整恢复。记录支持的系统与硬件条件。
- 建立可手动提交的反馈模板，包括复现步骤、错误编号、系统信息与经过用户检查的日志。默认不收集个人记录，不默认开启遥测。
- 发布前清点品牌、图标、第三方运行时、模型和素材授权；现在的角色原图仅用于个人界面，候选包不携带。

完成标准：少量试用者无需开发者代为修改配置就能开始使用；能独立恢复自己的资料；得到足够具体的反馈，再决定下一步定位。

当前没有联系试用者、上传发布包或确定收费与商业授权。应先完成试用包的安装、数据隔离、授权与恢复验收，再安排对外推广。

- 网站、商店页和宣传内容围绕已验证能力，清楚说明本机单人、模型首次联网准备、AI 需要人工确认等使用条件。

完成标准：发布包、演示与文档一致，可重复安装与升级；任何对外发布或推广联系都另行安排，当前构建不执行发布。

## 第五阶段：持续服务与商业化验证

**后续规划，尚未定价或承诺服务**：

- 先验证目标用户持续使用的原因、付费意愿和支持成本，再确定收费方式。
- 个人版可考虑更易安装、数据迁移和可选同步；行业经验库可考虑模板与知识结构。企业版须单独设计身份、权限、审计与隔离，不能直接把当前本机服务开放到网络。
- 优先保证数据可导出、备份可恢复，避免用户资料被绑定在某种模型或供应商上。

本阶段为规划。当前没有公开发行、商业授权结论、云服务承诺或多人安全保证。
